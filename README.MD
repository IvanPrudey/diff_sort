# Визуализатор алгоритмов сортировки

## Описание:
Приложение позволяет наглядно наблюдать за процессом работы алгоритмов сортировки в реальном времени. Каждый шаг алгоритма сопровождается цветовой подсветкой элементов, что делает процесс обучения и понимания алгоритмов более интуитивным.

## Доступные алгоритмы:
1. Пузырьковая сортировка ✅ Реализована
2. Сортировка выбором ✅ Реализована
3. Сортировка вставками ✅ Реализована

## Планируется еще к реализации:
1. Добавить показатель времени - за которое массив проходит сортировку - выполнено ✅

## Как запустить проект: 
Клонировать репозиторий и перейти в него в командной строке: 
``` 
git clone git@github.com:IvanPrudey/diff_sort.git 
``` 
``` 
cd diff_sort
```

Cоздать и активировать виртуальное окружение: 
``` 
python -m venv venv 
``` 
``` 
source venv/Scripts/activate 
``` 

Установить зависимости из файла requirements.txt: 
``` 
python -m pip install --upgrade pip 
``` 
``` 
pip install -r requirements.txt 
```

Запустить приложение в bash
```
python app.py
```
